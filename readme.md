# 猜数字小游戏
一个用 Python 编写的命令行猜数字游戏，适合 Python 初学者了解基础语法。

## 项目简介

电脑随机生成一个 1 到 100 之间的整数，玩家通过命令行输入猜测的数字。
程序会提示“大了”或“小了”，直到猜中为止，并统计总共猜了多少次。

## 环境要求

- Python 3.x（需已添加到系统环境变量）

## 运行方法

1. 打开命令提示符（Win + R，输入 cmd）
2. 切换到项目目录：
   cd D:\demo_do\first
3. 运行程序：
   python game.py
